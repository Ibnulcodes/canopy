# Canopy site
Static site for Canopy Furniture, Chattogram, in English and Bangla (`/bn/`).
Build: `node build.js` (Node 18+, no dependencies) writes the site to `dist/`. Preview: `npm run serve` rebuilds the site and serves it locally. Deploys on Vercel (`vercel.json`).

**How to edit products, categories, blog posts, photos and SEO: see [EDITING-GUIDE.md](EDITING-GUIDE.md).**

## Before going live
Edit `content/site.json`: `phone`, `whatsapp`, `email`, `domain`, and `formAction` (your Formspree or Netlify form URL).

## Online editor (/admin) one-time setup
The editor at `/admin/` (Decap CMS) saves markdown and JSON files to GitHub. Each save is a commit to `main`, and Vercel then rebuilds the site.
1. GitHub > Settings > Developer settings > OAuth Apps > New OAuth App.
   Homepage URL: your site URL. Callback URL: `https://YOUR-SITE/api/callback`
2. In Vercel > Project > Settings > Environment Variables, add `GITHUB_CLIENT_ID` and `GITHUB_CLIENT_SECRET` from that app, then redeploy.
3. The editor logs in through `domain` in site.json. If the site is not live on that domain yet, add `"cmsBaseUrl": "https://your-project.vercel.app"` to site.json.

The editor's form settings (`dist/admin/config.yml`) are generated by build.js. The category dropdowns always match `content/categories.json`.
The GitHub login code is in `api/auth.js` and `api/callback.js` (Vercel functions).
